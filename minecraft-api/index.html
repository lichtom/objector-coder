Minecraft 模组开发 API 文档

使用 Objector 积木快速生成 Minecraft 模组代码

概述

Objector 的 Minecraft 模组开发模式支持三个主流平台，让你通过拖拽积木的方式生成模组代码，无需手写复杂代码即可创建 Minecraft 模组。

🌍 基岩版 (Bedrock Edition)

目标平台：Minecraft 基岩版（Windows 10/11、移动设备、主机）

技术栈：JavaScript + Script API (@minecraft/server)

导出格式：.mcpack 文件

适用场景：国际版 Minecraft，功能丰富，API 现代化

🇨🇳 网易版 (NetEase Edition)

目标平台：网易我的世界中国版

技术栈：Python 2.7 + ModSDK

导出格式：.zip 压缩包

适用场景：中国市场，需要通过 MC Studio 发布

☕ Java 版 (Java Edition)

目标平台：Minecraft Java 版

技术栈：Java + Fabric Mod Loader

导出格式：.zip 压缩包

适用场景：PC 玩家，模组生态最成熟

基岩版 API 详解

Script API 基础

基岩版的 Script API 是微软官方提供的 JavaScript API，允许开发者通过脚本控制游戏行为。

核心模块

  • @minecraft/server - 服务端 API，控制游戏逻辑
  • @minecraft/server-ui - UI API，创建表单和对话框
  • world - 世界对象，访问游戏世界
  • system - 系统对象，处理定时器和事件

事件系统

// 监听玩家加入事件
world.afterEvents.playerJoin.subscribe((event) => {
    const player = event.player;
    player.sendMessage("欢迎加入游戏！");
});

// 监听方块被破坏事件
world.afterEvents.blockBreak.subscribe((event) => {
    const block = event.block;
    const player = event.player;
    console.log(`方块被破坏: ${block.typeId}`);
});

// 定时执行
system.runInterval(() => {
    // 每 20 tick（1秒）执行一次
    console.log("定时任务执行");
}, 20);

方块操作

// 放置方块
const dimension = world.getDimension("overworld");
dimension.runCommand(`setblock ${x} ${y} ${z} ${blockType}`);

// 填充区域
dimension.runCommand(`fill ${x1} ${y1} ${z1} ${x2} ${y2} ${z2} ${blockType}`);

// 替换方块
dimension.runCommand(`fill ${x1} ${y1} ${z1} ${x2} ${y2} ${z2} ${newBlock} replace ${oldBlock}`);

// 清除区域
dimension.runCommand(`fill ${x1} ${y1} ${z1} ${x2} ${y2} ${z2} air`);

实体操作

// 生成实体
dimension.runCommand(`summon ${entityType} ${x} ${y} ${z}`);

// 杀死附近实体
dimension.runCommand(`kill @e[type=${type},r=${radius}]`);

// 传送实体
dimension.runCommand(`tp @e[type=${type}] ${x} ${y} ${z}`);

玩家操作

// 传送玩家
dimension.runCommand(`tp @a ${x} ${y} ${z}`);

// 给予物品
dimension.runCommand(`give @a ${item} ${count}`);

// 设置游戏模式
dimension.runCommand(`gamemode ${mode} @a`);

// 添加效果
dimension.runCommand(`effect @a ${effect} ${duration} ${level}`);

世界设置

// 设置时间
dimension.runCommand(`time set ${time}`);

// 设置天气
dimension.runCommand(`weather ${weather}`);

// 设置游戏规则
dimension.runCommand(`gamerule ${rule} ${value}`);

// 发送消息
dimension.runCommand(`say ${message}`);

网易版 API 详解

ModSDK 基础

网易版使用 Python 2.7 和 ModSDK 框架，需要遵循特定的项目结构。

项目结构

MyMod/
├── entities/              # 必需的空文件夹
├── manifest.json          # 模组配置
├── pack_icon.png          # 图标
└── MyModScripts/          # 脚本文件夹（必须以Scripts结尾）
    ├── __init__.py        # Python 包标识
    └── modMain.py         # 入口文件（固定名称）

入口文件 modMain.py

# -*- coding: utf-8 -*-
import mod.client.extraClientApi as clientApi
import mod.server.extraServerApi as serverApi

# 注册模组
ClientApi = clientApi.GetClientApi()
ServerApi = serverApi.GetServerApi()

def ClientInit():
    ClientApi.RegisterSystem('MyMod', 'MyModClient', 'MyModScripts.MyClientSystem.MyClientSystem')

def ServerInit():
    ServerApi.RegisterSystem('MyMod', 'MyModServer', 'MyModScripts.MyServerSystem.MyServerSystem')

服务器系统

# -*- coding: utf-8 -*-
import mod.server.extraServerApi as serverApi

ServerApi = serverApi.GetServerApi()
compFactory = ServerApi.GetEngineCompFactory()

class MyServerSystem(ServerApi.GetServerSystemCls()):
    def __init__(self, namespace, systemName):
        super(MyServerSystem, self).__init__(namespace, systemName)
        
        # 监听事件
        self.ListenForEvent(
            ServerApi.engine_namespace,
            ServerApi.engine_system_name,
            'ServerChatEvent',
            self,
            self.OnChatEvent
        )
    
    def OnChatEvent(self, args):
        playerId = args['username']
        message = args['message']
        
        # 执行命令
        comp = compFactory.CreateCommand(ServerApi.levelId)
        comp.SetCommand('say ' + message)

常用命令

# 执行命令
comp = compFactory.CreateCommand(ServerApi.levelId)
comp.SetCommand('setblock ~ ~ ~ stone')
comp.SetCommand('give @a diamond 64')
comp.SetCommand('time set day')
comp.SetCommand('weather clear')

# 获取玩家位置
playerComp = compFactory.CreatePlayer(playerId)
pos = playerComp.GetPlayerPos()
x, y, z = pos['x'], pos['y'], pos['z']

# 设置玩家位置
playerComp.SetPlayerPos({'x': x, 'y': y, 'z': z})
⚠️ 重要提示：
  • 网易版必须使用 Python 2.7 语法
  • modMain.py 文件名固定，不可更改
  • 脚本文件夹必须以 Scripts 结尾
  • entities 文件夹必须存在（可以为空）
  • 需要通过 MC Studio 进行发布

Java 版 API 详解

Fabric Mod 基础

Java 版使用 Fabric Mod Loader，需要 Java 编程知识。

项目结构

├── gradle.properties
├── settings.gradle
└── src/

        │   └── com/
        │       └── example/
        │           └── mymod/
        │               └── MyMod.java
        └── resources/
            ├── fabric.mod.json
            └── assets/
                └── mymod/
                    └── textures/

主类 MyMod.java

package com.example.mymod;

import net.fabricmc.api.ModInitializer;
import net.fabricmc.fabric.api.event.lifecycle.v1.ServerTickEvents;
import net.minecraft.server.MinecraftServer;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class MyMod implements ModInitializer {
    public static final String MOD_ID = "mymod";
    public static final Logger LOGGER = LoggerFactory.getLogger(MOD_ID);

    @Override
    public void onInitialize() {
        LOGGER.info("模组已加载！");
        
        // 注册服务器 tick 事件
        ServerTickEvents.END_SERVER_TICK.register(this::onServerTick);
    }
    
    private void onServerTick(MinecraftServer server) {
        // 每 tick 执行
    }
}

最佳实践

1. 选择合适的平台

  • 基岩版：功能最丰富，API 现代化，适合新手
  • 网易版：中国市场必需，需要通过审核
  • Java 版：生态最成熟，模组兼容性最好

2. 代码组织

  • 使用 Objector 积木构建逻辑流程
  • 生成代码后手动优化性能
  • 添加适当的注释说明
  • 测试所有功能再导出

3. 性能优化

  • 避免在每 tick 执行复杂操作
  • 使用定时器而不是每 tick 检查
  • 限制实体搜索范围
  • 缓存常用数据

4. 调试技巧

  • 基岩版：使用 console.log()
  • 网易版：使用 print（Python 2.7）
  • Java 版：使用 LOGGER.info()
  • Objector：使用"打印"积木

常见问题

Q: 为什么我的模组在网易版无法运行？

A: 请检查：

  • 是否使用了 Python 2.7 语法（print 不加括号）
  • modMain.py 文件名是否正确
  • 脚本文件夹是否以 Scripts 结尾
  • entities 文件夹是否存在
  • 是否通过 MC Studio 正确发布

Q: 基岩版模组如何安装？

A: 导出的 .mcpack 文件可以直接双击安装，或者手动解压到：

Windows: %localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\behavior_packs\

Q: Java 版模组如何编译？

A: 使用 Gradle 构建：

./gradlew build

编译后的 .jar 文件在 build/libs/ 目录中。
