🖥️ 编辑器入门

Objector 是一款基于 Electron 的图形化积木编程桌面编辑器，支持 Windows 平台。

🎨

积木面板（左侧）

按分类浏览所有积木。点击分类名切换显示，将积木拖入画布即可使用。积木间通过端口自动吸附连接。

📐

积木画布（中央）

主要的编程区域。拖拽积木组合成程序。支持滚轮缩放、右键菜单（复制/删除/折叠/批注/Ctrl+T 跳转标签）。

🎭

舞台（右侧）

精灵活动的可视化区域。运行程序后精灵在此显示和移动。支持多精灵管理。

▶️

运行控制

工具栏提供 ▶ 运行 / ⏹ 停止 按钮。运行后所有 🚩"当程序启动时" 积木链开始执行。

🐛

开发者模式

切换到开发者模式可启用断点设置、单步执行、变量监视面板等高级调试工具。

📂

项目管理

新建项目时选择父文件夹，自动在其下创建"我的作品"子目录。支持项目重命名（同步更新磁盘目录名）。导出为 HTML 可分享给他人运行。

🔌

扩展系统

通过 JSON/JS 扩展文件自定义新积木类型。点击工具栏 📖 文档按钮可查看扩展编写指南。

🏷️

三种模式

新手模式：精简积木；普通模式：完整功能；开发者模式：调试工具。

积木形状说明： 帽子型 (hat) = 事件入口，程序从这里开始； 堆叠型 (stack) = 普通指令； C型槽 (c-block) = 包含子代码的容器； 报告器 (reporter) = 返回值； 布尔型 (boolean) = 返回真/假； C型报告器 = 代码块容器 + 返回值

事件

程序入口点和事件触发机制。所有程序至少需要一个事件帽子积木来启动。

积木形状说明
🚩 当程序启动时hat点击运行按钮后触发，是最常用的程序入口
⌨ 当按下 [key] 键hat按下指定键盘按键时触发，支持字母/数字/方向键/特殊键
👆 当精灵被点击hat鼠标点击当前精灵时触发
📡 广播 [msg]stack发送消息给所有"当接收到"积木，不等待执行完毕
📡 广播 [msg] 并等待stack发送消息并等待所有接收者执行完毕后再继续
📩 当接收到 [msg]hat接收到指定消息时触发，配合广播使用
⏱ 每隔 [sec] 秒hat定时触发，每隔指定秒数执行一次

标签与 Turbo

积木形状说明

元编程（v1.0.4 新增）

积木形状说明
代码块c-block-reporter将子代码封装为可传递的"值"。左上角 flow-in 被触发执行，正左中 param-out 输出代码块引用
运行 [🧩]stack接收积木引用并执行。支持代码块闭包、函数定义
运行 [🧩] 并返回reporter执行积木并返回其结果值
元编程示例：
1. 拖出一个"代码块"，内部放入子代码
2. 从代码块左侧 param-out 拖线到"运行 [🧩]"的输入槽
3. 运行时，代码块内的子代码会被执行
4. 也可以传给"设置函数 [名称] 定义为 [🧩]"来动态注册函数
