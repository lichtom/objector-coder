1. 高级模式简介

高级模式是 ObjectScratch 的 Godot 风格游戏开发界面，提供：

  • 场景树 — 层级化管理游戏对象（Sprite2D、Camera2D 等）
  • 文件系统 — 真实文件目录，管理贴图、脚本、场景文件
  • 属性检查器 — 实时编辑节点属性
  • 双模脚本编辑器 — 积木（图形化）或 JavaScript 代码，随时切换
  • 全屏编辑器 — 按 F11 进入全屏编程
  • 独立 JS 窗口 — 点击 ⧉ 在新窗口中编写代码
如何进入高级模式？ 在主页创建/打开项目时选择「高级模式」即可。

4. JavaScript 编程模式

切换到「JS 代码」标签即可使用 JavaScript 编程。代码在每个 Sprite2D 节点上独立运行。

可用变量与全局函数

在 JS 代码中，以下变量和函数可直接使用：

名称说明
sprite当前精灵的 API 代理对象（见下方完整 API）
stage全局舞台 API 对象（鼠标、舞台尺寸等）
globalVars全局变量对象，所有精灵共享
log(msg)输出到输出面板
say(text)说话（等同 sprite.say(text)）
sayFor(text, sec)说话 N 秒后消失
think(text)思考气泡
move(steps)前进 N 步
turnRight(deg)右转 N 度
turnLeft(deg)左转 N 度
show()显示精灵
hide()隐藏精灵
setSize(sz)设置大小
changeSize(n)改变大小
运行时机： JS 代码在积木的 event_start（绿旗）执行完毕后自动运行。如果没有绿旗积木，JS 代码在点击运行按钮后立即执行。

独立 JS 编辑窗口

点击脚本标签栏的 ⧉ 按钮，可以打开独立的 JS 代码编辑窗口，支持：

  • 完整的代码高亮、自动括号匹配、代码折叠
  • 窗口可自由移动、最大化、全屏（F11）
  • Ctrl+S 保存并关闭 / Ctrl+Shift+S 应用代码保持窗口打开
  • 代码实时同步到主编辑器

6. 实用示例代码

6.1 基础移动 + 说话

// 精灵向前走 50 步，然后说话
move(50);
say("我走了 50 步！");
log("当前位置: " + sprite.x + ", " + sprite.y);

6.2 键盘控制移动

// 通过直接读取属性实现方向控制
if (stage.isKeyPressed('ArrowRight')) {
  sprite.x += 5;
  sprite.pointInDirection(90);
}
if (stage.isKeyPressed('ArrowLeft')) {
  sprite.x -= 5;
  sprite.pointInDirection(-90);
}
if (stage.isKeyPressed('ArrowUp')) {
  sprite.y += 5;
  sprite.pointInDirection(0);
}
if (stage.isKeyPressed('ArrowDown')) {
  sprite.y -= 5;
  sprite.pointInDirection(180);
}

6.3 跟随鼠标

// 面向鼠标并移动
sprite.pointTowards(stage.mouseX, stage.mouseY);
sprite.moveTowards(stage.mouseX, stage.mouseY, 5);

6.4 简单物理：重力 + 弹跳

// 设置初始速度（向上抛）
sprite.setVelocity(0, 8);

// 每帧更新
sprite.applyGravity(-0.5);   // 重力向下
sprite.updateVelocity();     // 更新位置

// 碰到地面弹跳
if (sprite.y < -170) {
  sprite.y = -170;
  sprite.vy = Math.abs(sprite.vy) * 0.7; // 反弹，损失 30% 能量
  sprite.applyFriction(0.98);
}

6.5 精灵碰撞检测

// 检测是否碰到另一个精灵
if (sprite.isTouchingSprite("敌人")) {
  sprite.say("被碰到了！");
  sprite.hide();
  log("游戏结束！");
}

6.6 使用全局变量计分

// 精灵 A：初始化分数
globalVars.score = 0;
sprite.say("按空格键得分！");
// 精灵 B：在另一个节点上检测加分
if (stage.isKeyPressed('space')) {
  globalVars.score += 1;
  sprite.sayFor("得分: " + globalVars.score, 1);
}

6.7 造型切换动画

// 循环切换造型（需要已上传多个造型）
sprite.nextCostume();
// 或者指定名称
sprite.setCostume("walk2");

6.8 随机出现 + 克隆

// 随机移动到舞台某处
sprite.goToRandomPosition();
sprite.say("我在这！");

// 克隆一个分身
const cloneIdx = sprite.clone();
log("克隆体索引: " + cloneIdx);

7. 技巧与常见问题

积木和 JS 可以混用吗？

可以！积木代码（event_start 积木）会先执行，然后 JS 代码再执行。你可以在积木中搭建场景和初始化，在 JS 中编写复杂逻辑。

JS 代码什么时候运行？

点击运行按钮后：

  1. 所有 event_start（绿旗）积木先执行
  2. 每个精灵的 JS 代码按顺序执行
  3. 如果有按键/定时器积木，进入事件循环等待

多个精灵的 JS 代码会互相干扰吗？

每个精灵的 sprite 变量指向自己，不会干扰。但 globalVars 是共享的，可以用来在精灵之间传递数据。

如何让代码每帧重复执行？

目前 JS 代码是单次执行的。要实现每帧循环，可以：

  • 在积木中添加一个「重复执行」积木，在 JS 中使用 setInterval
  • 或者使用 sprite.updateVelocity() 配合速度系统
// 每 30ms 更新一次位置（约 33fps）
setInterval(() => {
  sprite.applyGravity(-0.3);
  sprite.updateVelocity();
  if (sprite.y < -170) { sprite.y = -170; sprite.vy *= -0.8; }
}, 30);
注意： sprite 对象是一个代理，修改属性会立即反映到精灵上。不要将 sprite 赋给其他变量后修改副本——副本不会同步到舞台。始终直接操作 sprite.x、sprite.y 等属性。

支持 ES6+ 语法吗？

支持！ 可以使用箭头函数、模板字符串、解构、async/await 等所有现代 JS 特性。
